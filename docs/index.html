06 // WEB CLIENT

不装 App 也能学BROWSER-NATIVE CPYTHON 3.13 · SAME COURSES, SAME ENGINE

网页版 · 在线试玩

PYODIDE 0.29.5 · CPYTHON 3.13.2 · 无需注册
  • 与手机端同一套课程 JSON与同一份 runner.py
  • 执行在 Web Worker 内，死循环可强制终止，不冻结页面
  • 进度 / XP 存本机 localStorage，刷新与深链可恢复
  • 首屏需联网下载约 12 MB WASM 内核（浏览器缓存后复用）
  • 需要现代浏览器 Chrome / Edge / Firefox / Safari 16.4+
打开网页版
网页版是 App 的子集：6 道 Python 挑战可判题，2 道 JavaScript 挑战请在 App 内体验；成就 / 连击 / 证书等 Android 专属功能不在网页端。
// SAME ENGINE, TWO RUNTIMES
# Android: CPython 3.13 via Chaquopy ./gradlew :app:assembleDebug # Web: same runner.py in Pyodide cd web python -m http.server 8765 # 两端课程同源校验 python tests/validate_content.py

为什么同源很重要：判题语义只在 runner.py 里写一次，App 与网页端行为一致；课程 JSON 只维护一份，避免「网页讲的和手机讲的不一样」。

08 // FAQ

常见疑问BEFORE YOU ASK

真的是 100% 离线吗？那要网络权限干嘛？
学习、写码、判题 100% 离线——CPython 3.13 解释器直接嵌在 APK 里。联网仅当你手动在「内容中枢」检查/下载新课程包时发生，且零个人数据上传。
和 Pydroid3 这类 IDE 有什么区别？
Pydroid 是开发工具；CodeLearning 是「课程即代码」的学习终端——每讲自带判题挑战与成长体系。我们的目标是教会你，而不是只给你一个空白编辑器。
会有 iOS 版吗？
当前技术栈（Chaquopy）仅支持 Android；iOS 需要另一套方案，已列入长期路线图。
可以商用吗？
可以。项目以 MIT License 开源——可自由使用、修改、分发（含商用），只需保留许可声明。详见仓库 LICENSE。
